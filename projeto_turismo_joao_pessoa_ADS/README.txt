PROJETO - TURISMO EM JOÃO PESSOA
Análise e Desenvolvimento de Sistemas

Estrutura:
- index.html = página Home
- praias.html = página sobre praias
- pontos.html = página sobre pontos turísticos
- css/style.css = estilos do site
- js/script.js = JavaScript
- img/ = imagens/ilustrações usadas no projeto

COMO EXECUTAR:
1. Extraia o arquivo ZIP.
2. Abra a pasta do projeto.
3. Dê dois cliques em index.html.
4. Navegue pelo menu para acessar as outras páginas.

OBSERVAÇÃO:
As imagens locais são ilustrações simples incluídas no projeto para que o site funcione mesmo sem internet.
As informações sobre os locais foram organizadas a partir de referências turísticas sobre João Pessoa.
